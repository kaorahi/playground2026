レーティング差と勝率

レーティングに差があるほど勝率が片寄ります。

プレイヤーAの勝率 = 1 1 + 10-(RA - RB) / 400
RA：プレイヤーAのレーティング
RB：プレイヤーBのレーティング
グラフをクリックすると値を確認できます。

レーティングの更新

試合後は、勝者のレーティングを引き上げ、敗者のレーティングを引き下げます。ただし更新量は一定ではなく、上位者が勝った試合では小さく、下位者が勝った試合では大きく更新します。これを繰り返すことで、各プレイヤーの勝ちやすさを反映したレーティングへと徐々に近づいていきます。

ΔRA = K(SA - EA)
EA = 1 / (1 + 10-(RA - RB) / 400)
ΔRA：試合前のプレイヤーAのレーティング更新量
K：更新の大きさを決める係数
SA：試合結果（Aの勝ちなら1、負けなら0）
EA：試合前に予測されるプレイヤーAの勝率
RA：試合前のプレイヤーAのレーティング
RB：試合前のプレイヤーBのレーティング
グラフをクリックすると値を確認できます。
