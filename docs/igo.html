「囲う」が見える囲碁入門

相手の石を囲んで取りましょう。色のついたふちをすべてふさげば、その石を取れます。

クリック時：

遊び方

ルール

  • 同じ色の石は縦横につながって、空き地側のふちに色がつきます。色のついたふちをすべてふさげば、その石塊は消えます。
  • 打ちたいところがなくなるまで打って、盤上の石が多いほうが勝ちです。白には7.5のハンデがつきます。

操作

  • 両者が続けてパスすると終局します。
  • 最後まで埋めるのがめんどうになったら、自動終局ボタンを使ってください。
  • 「自由に並べる」モードでは、右クリックでも石を消せます。

FAQ

  • 自動終局ボタンが2マス空きで止まるのはなぜ？
    → 1マス空きにしてしまうと、相手にそこへ打たれて、全部取られてしまいます。
  • 自動終局が正しくない
    → 賢い判断はできません。「あとは埋めればいいだけ」になるまで打ってから、自動終局ボタンを押してください。
  • 勝つコツは？
    → 純碁の解説動画はいかがでしょう。最初のほうのルール解説はこのアプリの種明しになっていて、第6回からが作戦の考え方です。
